# Onyx Bill Organizer — Privacy Policy and Support

The privacy policy and support page for the Onyx Bill Organizer iOS app, published with GitHub Pages:

- Privacy policy (`index.html`): https://speedzoner.github.io/onyx-privacy/
- Support (`support/index.html`): https://speedzoner.github.io/onyx-privacy/support/

The privacy policy's address is built into the app (`PremiumLinks.privacy`), and both addresses are set on the App
Store Connect record, so keep them the same: edit the files in place. Update the policy's "Last updated" date when it
changes.
